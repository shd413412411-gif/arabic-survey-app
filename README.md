# استبيان نفسي

تطبيق ويب عربي باتجاه RTL لإدخال إجابات استبيان من 28 بندًا وحفظها محليًا.

**الموقع المنشور:** https://arabicsurvey-kcfgxwcy.manus.space

## المزايا

- عرض البنود في قائمة أو إدخال متتابع.
- حفظ محلي في المتصفح، دون إرسال سجلات الإجابات إلى خادم.
- احتساب البنود العكسية.
- استيراد ملفات JSON وExcel وتصدير السجلات إلى Excel.
- دعم PWA والتخزين للعمل دون اتصال بعد التحميل الأول.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

التحقق من الأنواع والبناء:

```bash
pnpm check
pnpm build
```

## ملاحظة حول بيانات البنود

أضف نصوص البنود الفعلية في مصفوفة `QUESTION_TEXTS` داخل `client/src/pages/Home.tsx` قبل استخدام التطبيق لاستبيان حقيقي. لا يحتوي المستودع على إجابات مستخدمين؛ سجلات كل مستخدم محفوظة محليًا في متصفحه، ويمكن تصدير نسخة احتياطية من داخل التطبيق.
